# Ley Lines: corrections and suggestions

[Ley Lines](https://leylines.cryptideffects.com) maps guitar-pedal lineage: which circuits came
from which, and the circuit blocks they share. This repository collects corrections, new pedals
and answers to open questions. The site's code and data are kept elsewhere.

- **[Correct a record](https://github.com/drlholloway/ley-lines/issues/new?template=correction.yml)**:
  a wrong date, maker, link or summary, or an answer to a record marked "needs review".
- **[Suggest a pedal](https://github.com/drlholloway/ley-lines/issues/new?template=new-pedal.yml)**:
  a pedal, kit or layout the map is missing.
- **[Open questions](https://leylines.cryptideffects.com/review.html)**: the records we're least
  sure of.

## What makes a suggestion usable

Every link on the map cites a source, so please give one: a maker's page, a manual, a schematic,
a magazine article or interview, a kit's build document, or a forum thread where someone traced
the circuit. Say which it is; a maker's own statement counts for more than a forum guess, and
both are welcome.

Please describe things in your own words rather than pasting text from other sites.
